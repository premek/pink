Test cases in this directory are organised by prefix:

  I*   — taken from ink-proof: https://github.com/chromy/ink-proof
  W*   — taken from official language specification: https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md
  P*   — written for this project

Normally the transcript.txt files are generated by inklecate (the reference Ink interpreter):

  inklecate -p story.ink < input.txt > transcript.txt

Exceptions
----------
Tests that involve random output cannot be reproduced directly because Lua
and C# use different random number generators — the same seed produces
different sequences in each. For these tests the story.ink is modified to
include a ~SEED_RANDOM(n) call, and a seed is found by trying different values
until both inklecate and Pink produce identical output. The transcript is
then regenerated from inklecate using that seed.

Some tests had to be shortened because no common seed was found for them.
