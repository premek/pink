Test cases in this directory are organised by prefix:

  I* - taken from ink-proof: https://github.com/chromy/ink-proof
  W* - taken from official language specification: https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md
  P* - written for this project
  X* - incompatible with ink - extensions, improvements (do not regenerate using inclecate)

Normally the transcript.txt files are generated by inklecate (the reference Ink interpreter):

  inklecate -p story.ink < input.txt > transcript.txt

RNG tests
---------
Tests that involve random output use ~ SEED_RANDOM(N) to fix the sequence.
Pink uses a Park-Miller LCG (pink/random.lua) that is identical across all
Lua versions and machines, but differs from inklecate's C# System.Random.
Finding a seed where both produce the same output requires a short search.

For most RNG tests the seed lives in a setup.ink file alongside story.ink:

  ~ SEED_RANDOM(N)
  INCLUDE story.ink

The test runner uses setup.ink instead of story.ink when present.

Use test/runtime/seed_search.sh to find a matching seed, write setup.ink,
and regenerate transcript.txt in one step:

  ./test/runtime/seed_search.sh TESTNAME
